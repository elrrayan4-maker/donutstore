How to Install Mods

Follow these steps to get started with Fabric and enjoy Donut SMP

01

Fabric Loader

Download and install Fabric Loader for Minecraft 1.21 from the official website.

Visit Fabric Website →
02

Fabric API

Download Fabric API and place it in your mods folder.

Get Fabric API →
03

Open .minecraft

Press Win + R, type %appdata%\.minecraft and locate the mods folder.

04

Drop .jar files

Put all downloaded mod .jar files into the mods folder.

05

Launch & Play

Start Minecraft with the Fabric 1.21 profile and enjoy Donut SMP!
